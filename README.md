# fluffy-octo-broccoli

一个从本地空文件夹初始化的 Git 练习 / 脚手架仓库。

## 仓库信息

- 远程地址: https://github.com/D66881/fluffy-octo-broccoli.git
- 默认分支: `main`

## 快速开始

```bash
git clone https://github.com/D66881/fluffy-octo-broccoli.git
cd fluffy-octo-broccoli
```

## 目录结构

```
.
├── README.md
└── .gitignore
```

## 说明

本仓库的初始内容由 `git init` 脚手架生成，用于验证本地到 GitHub 的
完整工作流（init → commit → push）。后续可在此基础上添加实际项目代码。

## 提交约定

建议使用约定式提交（Conventional Commits）：

- `feat: 新增功能`
- `fix: 修复问题`
- `docs: 文档变更`
- `chore: 构建 / 依赖 / 杂项`
